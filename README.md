# fomo-kun

使用者の **FOMO（Fear of Missing Out / 見逃すことへの不安）** を自覚・解消するための、内省・セルフケア型ツールです。

`index.html` をブラウザで開くだけで動作します。サーバー・ビルド・パッケージ管理・依存ライブラリは一切ありません。

## できること

1. 今の落ち着かなさが **FOMOなのか／そうでないのか を自覚** する
2. その不安を **解消（手放す）** 方向へ導く

このツールが **やらないこと**：FOMOを煽らない。他人の充実や「みんなが見ている」情報を見せない。数値や連続記録で競わせない。プレッシャー（義務感）を生まない。

## 使い方

ビルド不要です。次のいずれかで開きます。

- `index.html` をブラウザでそのまま開く
- もしくは任意の静的サーバーで配信する：

```
npx --yes http-server -p 8777 -c-1
```

> `python` はこの環境では Windows ストアのスタブで動かないため、Node を使ってください。

## 体験フロー

```
[1] 入口画面
      ↓
[2] 自覚ステップ（A/B切り分け）
      ├─ A: 具体的に何かを見逃している気がする   → [3A]
      └─ B: 理由はないけど何となく落ち着かない    → [3B]
      ↓
[3A] FOMOワーク：書き出し → 認知再構成の問い返し → 「見逃してOK」で手放す
[3B] 切り分け結果：「これはFOMOではないかもしれません」
      ↓
[4] 一言記録（任意）→ ログに保存
      ↓
[5] 締め画面（静かに終わる）

[*] 振り返り：入口からいつでも過去ログを閲覧／全消去できる
```

## データとプライバシー

- ログはブラウザの `localStorage`（キー：`fomo-kun:logs`）にのみ保存され、**外部へ送信しません**。
- データは端末内のみに残ります。**振り返り画面からいつでも全消去**できます。
- 通信を行わないため、オフラインで完全に動作します。
- 1エントリの構造：

```json
{
  "id": "string (一意ID)",
  "timestamp": "ISO 8601 文字列",
  "type": "A | B",
  "concern": "string | null",
  "note": "string | null"
}
```

## 設計思想

- **悪化させない**：煽り・競争・他者比較を排除。アニメーションは穏やかで短く、注意を奪わない。
- **プレッシャーを与えない**：すべてのワークはスキップ可能。「やらなければ」と思わせる文言を避ける。
- **プライバシー**：データは端末内のみ。いつでも全消去できることを明示。
- **堅牢性**：`localStorage` が使えない環境でも、保存なしで動作を継続する（読み込み失敗時は空配列にフォールバック）。
- **アクセシビリティ**：十分なコントラスト、キーボード操作可、system font stack。
